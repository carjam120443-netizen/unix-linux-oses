# Linux & Unix Distro Links 🐧

A central list of official websites and download pages for the distributions documented in this repository.

> **Note:** This file is a manually maintained index. When a distro is added to `README.md`, add it here too. GitHub Markdown links will appear blue and clickable.

## 🌐 Popular Linux Distributions

| Distribution | Official Website | Description |
|---|---|---|
| [Ubuntu](https://ubuntu.com/) | https://ubuntu.com/ | User-friendly Debian-based Linux distribution with a huge software ecosystem. |
| [Debian](https://www.debian.org/) | https://www.debian.org/ | Stable and versatile Linux distribution and a foundation for many others. |
| [Fedora](https://fedoraproject.org/) | https://fedoraproject.org/ | Modern Linux distribution backed by Red Hat. |
| [Arch Linux](https://archlinux.org/) | https://archlinux.org/ | Minimal and highly customizable Linux distribution. |
| [CachyOS](https://cachyos.org/) | https://cachyos.org/ | Performance-focused Arch-based distribution. |
| [Linux Mint](https://linuxmint.com/) | https://linuxmint.com/ | Beginner-friendly desktop distribution based on Ubuntu/Debian. |
| [openSUSE](https://www.opensuse.org/) | https://www.opensuse.org/ | Linux family known for YaST and multiple release models. |
| [Manjaro](https://manjaro.org/) | https://manjaro.org/ | User-friendly Arch-based distribution. |
| [Kali Linux](https://www.kali.org/) | https://www.kali.org/ | Debian-based distribution focused on security testing and digital forensics. |
| [Pop!_OS](https://system76.com/pop/) | https://system76.com/pop/ | Ubuntu-based desktop distribution developed by System76. |
| [Zorin OS](https://zorin.com/os/) | https://zorin.com/os/ | Desktop-focused distribution designed to make switching to Linux easier. |
| [Gentoo](https://www.gentoo.org/) | https://www.gentoo.org/ | Highly customizable source-based Linux distribution. |
| [NixOS](https://nixos.org/) | https://nixos.org/ | Declarative Linux distribution built around the Nix package manager. |
| [Athena OS](https://athenaos.org/) | https://athenaos.org/ | Arch-based distribution focused on cybersecurity, privacy, and security tools. |

## 🔄 Keeping This List Updated

When adding a new distribution to `README.md`, add the same distribution to this file. This repository currently does not automatically generate this list from the README, so the two files should be updated together.

## 📜 Disclaimer

This is an unofficial index. The projects listed here are independent of this repository. Always use the official project website for the newest releases, checksums, signatures, and installation instructions.
