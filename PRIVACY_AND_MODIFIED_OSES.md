# Privacy-Focused Operating Systems 🔒

Operating systems and distributions that emphasize privacy, security, anonymity, free software, or minimizing unnecessary data collection.

- [Tails](https://tails.net/) — Debian-based live operating system designed to help preserve privacy and anonymity.
- [Qubes OS](https://www.qubes-os.org/) — Security-focused operating system that isolates tasks using virtual machines.
- [Whonix](https://www.whonix.org/) — Privacy-focused operating system designed around the Tor network and isolation.
- [GrapheneOS](https://grapheneos.org/) — Privacy and security-focused mobile operating system based on Android.
- [CalyxOS](https://calyxos.org/) — Android-based mobile operating system focused on privacy, security, and user choice.
- [PureOS](https://pureos.net/) — Debian-based distribution focused on privacy and free software.
- [Kicksecure](https://www.kicksecure.com/) — Security-hardened Debian-based operating system with privacy-oriented defaults.
- [Kodachi](https://www.digi77.com/linux-kodachi/) — Privacy-focused Linux distribution designed around anonymity and security tools.
- [Parrot OS](https://www.parrotsec.org/) — Debian-based distribution with privacy, security, development, and forensic tools.
- [LibreCMC](https://librecmc.org/) — Free-software-focused embedded Linux distribution for supported routers.

> 🔐 **Note:** A privacy-focused OS cannot guarantee complete anonymity or privacy by itself. Your applications, network, accounts, browser settings, and online behavior still matter.

# Modified & Modded Operating Systems 🛠️

Operating systems that have been modified, rebuilt, customized, forked, or repackaged from another operating system. This includes projects that change the desktop, packages, kernel, installer, repositories, system tools, or overall experience.

- [RebuiltTux](https://github.com/carjam120443-netizen/rebuilttux-iso) — Custom Linux ISO project experimenting with rebuilding and customizing Linux systems.
- [Re-buntu](https://github.com/carjam120443-netizen/re-buntu) — Customized Ubuntu-based project with modified system components and branding.
- [Rebuilt Gentoo](https://github.com/carjam120443-netizen/rebuilt-gentoo) — Custom Gentoo experimentation and rebuilding project.
- [Rebuilt NixOS](https://github.com/carjam120443-netizen/rebuilt-nixos) — Custom NixOS experimentation and rebuilding project.
- [Rebuilt Fedora](https://github.com/carjam120443-netizen/rebuilt-fedora) — Customized Fedora rebuilding project.
- [Re-builty OS](https://github.com/carjam120443-netizen/rebuilty-os) — Modified operating system project based around ReactOS.
- [Android-x86](https://www.android-x86.org/) — Project bringing Android to x86 PCs, with many community modifications and derivative builds.
- [Bliss OS](https://blissos.org/) — Android-based operating system project optimized and customized for PCs and other devices.
- [LineageOS](https://lineageos.org/) — Android-based open-source operating system with extensive customization and community development.
- [CachyOS](https://cachyos.org/) — Arch-based distribution with customized kernels, packages, and performance-oriented system configuration.
- [Garuda Linux](https://garudalinux.org/) — Arch-based distribution with heavily customized desktop environments, tools, and system defaults.
- [Athena OS](https://athenaos.org/) — Arch-based cybersecurity distribution with customized tools, repositories, and configurations.

> 🧩 **What counts as modified?** This section is for OS projects that go beyond simply installing software after installation. Customized ISOs, forks, rebuilds, remixes, and derivative operating systems all fit here.
